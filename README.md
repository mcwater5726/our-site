# 朱迪与1150 · 云端恋爱手账

兔兔主题的公开情侣小窝。照片与手账保存在D1和R2，访客只读，主人通过ChatGPT登录后可以添加照片和编辑手账。

## 日常使用
- 打开原网站链接即可浏览同一份云端相册。
- 点击主人登录，用网站主人的账号登录后管理。
- 本机旧照片不会自动公开。在小窝设置里选择本机照片同步，或导入此前导出的回忆备份。
- 备份导入会合并照片，不删除已有云端照片。照片编号幂等，失败后可以安全重试。
- 照片有八座城市分类；上传时会压缩到最长边1600像素。
- 仍可下载包含全部云端图片的JSON备份。

## 项目与运行
public/ 是前端源文件；worker/ 是云端API与入口；drizzle/ 是数据库迁移。
node scripts/build.mjs 构建为dist/server/index.js，无第三方运行依赖。
node scripts/preview.mjs --owner 启动独立4174本机预览，主人身份模拟仅存在本地适配器中，不会打包到正式网站。
node --test tests/cloud.test.mjs 验证匿名读取、主人鉴权、照片保存、幂等、软删除、版本冲突、失败补偿和输入校验。

## 权限与保存
公开访客只能读取。上传、删除、导入和手账保存需要平台注入的已登录身份，并匹配服务端OWNER_EMAIL秘密。
所有写请求还要求同源Origin。照片文件只接受可验证的JPEG、PNG或WebP；本机备份保留不清除。
删除采用云端软删除；旧备份不会以相同编号悄悄复活已移除照片。
手账使用版本检查，避免两个设备的过时编辑覆盖新内容。
个人备份、测试运行数据、预览截图不进入源码仓库和发布包。
